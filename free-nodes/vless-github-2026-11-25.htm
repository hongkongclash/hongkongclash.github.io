4.3 关注节点“健康度”：定期清理“僵尸节点”

订阅源中的节点并非全部可用。在v2rayN中，你可以全选节点，右键选择“测试服务器真连接延迟”，并勾选“仅显示可用节点”。这样，客户端会自动隐藏无法连接的节点，只保留“活着的”节点，避免你频繁手动切换。

五、常见故障排查：当“自由之路”亮起红灯

Q1：节点显示可用，但无法访问网页？ - 检查系统代理是否已开启。在v2rayN中，确认底部状态栏显示“代理已开启”。 - 尝试更换浏览器或清除浏览器缓存。部分浏览器插件（如SwitchyOmega）可能干扰代理设置。 - 在客户端中，将“DNS策略”改为“1.1.1.1”或“8.8.8.8”，避免DNS污染。

Q2：连接时提示“认证失败”或“握手超时”？ - 这通常意味着节点信息已过期或服务器已关闭。请更新订阅或更换其他节点。 - 检查本地系统时间是否准确。vmess协议对时间偏差敏感，如果系统时间与真实时间相差超过90秒，连接将失败。请同步网络时间。

Q3：速度很慢，视频卡顿？ - 优先选择延迟低、丢包率低的节点。在v2rayN中，通过“测试真连接延迟”筛选出速度最快的节点。 - 尝试更换传输协议。在节点配置中，将TCP改为WebSocket或gRPC，有时能明显提升速度。 - 关闭本地其他占用带宽的软件（如迅雷、在线备份等），确保带宽充足。

Q4：订阅链接无法更新？ - 检查订阅链接是否过期或失效。可以尝试在浏览器中直接打开该链接，看是否返回一串JSON格式的节点数据。 - 部分订阅源开启了防盗链或IP限制，可尝试更换网络环境（如从WiFi切换到手机热点）再更新。

Clash 的 Rule Provider 有什么作用？
Rule Provider 是 Clash 的规则分发机制。用户可以订阅不同的规则集，比如广告拦截、社交媒体、流媒体等，实现按需加载。它让配置文件更加简洁、动态更新，并支持多源规则管理。
Potatso Lite 是否支持手动节点管理？
支持。用户可手动输入节点信息或扫描二维码导入节点，并可进行修改或删除。虽然不支持自动订阅更新，但足以满足轻量用户对节点管理和流量分流的需求。
Matsuri 节点延迟排序如何提高访问速度？
Matsuri 定期测速节点延迟，结合策略组自动选择延迟最低节点处理流量。用户无需手动切换节点即可保持高速访问，提高网页浏览、视频播放和游戏体验的稳定性。
Netch 全局代理与规则代理的区别是什么？
全局代理会将所有流量通过节点转发，适合游戏或全局科学上网；规则代理只针对指定应用或 IP 走节点，优化带宽利用和网络效率，根据不同需求选择使用模式。
Trojan 使用自签名证书会带来哪些问题？
自签名证书无法被客户端默认信任，可能导致连接失败或需要手动安装证书。它也容易被中间人伪造识别，不利于长期生产环境安全部署，建议使用可信 CA 证书以获得更好兼容性与安全性。
Clash 是否支持 DNS 分流？
支持。Clash 可以自定义 DNS 服务器，并通过 rules 区分国内外域名解析方式。比如国内网站可使用本地 DNS，国外网站可走代理 DNS，从而提升访问速度与稳定性。
